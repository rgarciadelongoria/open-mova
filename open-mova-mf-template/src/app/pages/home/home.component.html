PUNTO DE PARTIDA

Una guía interactiva que también es un microfrontal.

Este proyecto se carga de forma remota desde la shell y es una referencia práctica para entender cómo crear una aplicación Open Mova con Angular y Native Federation.

Úsalo como demo

Recorre las capacidades nativas, revisa el código de cada ejemplo y ejecútalo desde una shell con Capacitor.

Úsalo como punto de partida

La CLI puede crear una aplicación con este perfil. Conserva la estructura que te sirva y sustituye el resto por tu lógica de negocio.

Separa responsabilidades

El microfrontal solo depende del contrato de @open-mova/core; la implementación nativa permanece dentro de la shell.
