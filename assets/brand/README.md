# Recursos de marca

Variantes oficiales del logotipo de Open Mova para documentación y comunicación.

- `open-mova-logo-title-rectangle.png`: opción recomendada para README con fondo claro.
- `open-mova-logo-dark.png`: opción recomendada para README o superficie oscura.
- `open-mova-logo-title-square.png`: composición vertical para espacios estrechos.
- `open-mova-logo.png`: isotipo sin texto.
- Archivos terminados en `-big`: variantes de mayor tamaño para usos que lo necesiten.

Para enlazar una imagen desde el README raíz usa una ruta relativa, por ejemplo:

```md
![Open Mova](assets/brand/open-mova-logo-title-rectangle.png)
```
